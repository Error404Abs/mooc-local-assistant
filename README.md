# MOOC 视频弹题助手

Tampermonkey 用户脚本 + 本机 Node.js 服务：读取视频中的文字弹题，通过兼容 Responses API 的服务请求答案，选择、提交并读取平台反馈。遇到不确定答案或错误时暂停。

这是非官方项目，与中国大学 MOOC、课程提供方、Moflux 或 OpenAI 没有隶属或授权关系。请先确认平台规则、课程要求及你是否有权自动处理相关题目；不要用于禁止自动作答的考试、考核或伪造学习记录。开源许可证不代表平台许可。

## 支持范围与限制

- 目前仅匹配 `icourse163.org`，并限制课程名为《中国文化传承与科技创新》，不是通用网课脚本。
- 支持文字单选、多选，以及 ✓／✗ 或已适配的 MOOC 正确／错误图标判断题；图片题、公式题、未知控件暂停。
- 同一弹窗防重复提交，请求过程中题目变化或人工操作会停止自动处理。
- 平台明确判对后继续学习；答错、未知反馈、API 错误、浏览器阻止播放均暂停。
- 仅缓存平台明确提供的正确答案，按选项内容匹配，避免选项换序后套错字母。
- 沿用页面的“自动播放下一视频”，不修改学习进度、播放速度或绕过平台验证。
- AI 可能给出错误答案，即使没有返回“不确定”。缺少视频上下文时仍可能需要人工处理，不能保证无人值守完成。

## 安装与使用

1. 安装 [Node.js](https://nodejs.org/) 22 或更新版本，以及 Chrome / Edge 的 [Tampermonkey](https://www.tampermonkey.net/)。按扩展提示启用“允许用户脚本”。
2. 下载仓库 ZIP 并解压。需要修改模型、地址或端口时，将 `config.example.json` 复制为 `config.json` 后编辑；不复制也会使用示例中的默认值。不要将 API key 写入配置。
3. Windows 双击 `启动.cmd`，其他系统在项目目录运行 `node server.mjs`。运行服务无需安装 npm 依赖。
4. 按提示输入 API key（隐藏输入，仅保留在本次进程中），或事先通过进程环境变量 `MOFLUX_API_KEY` 提供。默认 Moflux 接口和模型是否可用取决于你的账号权限，本项目不附带额度。
5. 将 `mooc-assistant.user.js` 的完整内容粘贴到 Tampermonkey 新建脚本中，保存。刷新课程视频页面。
6. 在助手面板填写启动窗口的连接码，默认端口 `17863`。连接码用于本机认证，不是 API key。
7. 首次遇到题目先点“检查页面”，确认题干、题型和选项完整，再点“开始”。只读检查不调用 AI、不提交。先在允许测试的非计分题上验证，勿直接用计分题试错。

以后每次先启动本机服务，再在课程页面点“开始”。保持服务窗口、课程页面打开，电脑不要休眠。保持网站“自动播放下一视频”勾选；浏览器冻结后台标签可能影响运行。

修改 `config.json` 后需重启服务；修改用户脚本文件不会自动更新 Tampermonkey，需要重新粘贴、保存并刷新。更换端口后也要更新面板端口。

## 结果、费用与隐私

面板显示绿色“答对了”、红色“答错了”或黄色“平台结果未确认”，依据平台反馈而非模型自评。判断不明确时不自动重试已提交题目。人工处理当前题目后可再次开始。

页面检测和“检查页面”只在本机执行，不消耗模型 token。未命中确认答案缓存的新题会请求 AI 并按服务商规则计费；按暂停时已经发出的请求仍可能产生费用。费用上限应在服务商平台设置。

服务仅监听 `127.0.0.1`，浏览器请求需要连接码。发送给 AI 的内容是课程名、题干、题型和选项，不发送账号、Cookie、整页截图或视频。请求设置 `store: false`，但第三方服务如何保存数据仍取决于其隐私政策，不能保证零留存。

`local-data/pairing-code.txt` 保存连接码，`local-data/answers-cache.json` 保存题目确认答案。不要共享这些文件、密钥或包含它们的截图。`.gitignore` 不是泄漏防护保证，发布前仍需人工检查；密钥泄漏时立即在服务商处撤销并更换。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 没有面板 | 检查域名、适配课程、脚本是否启用及扩展是否允许用户脚本，再刷新。 |
| 无法连接 | 确认服务窗口打开、端口一致、没有重复启动服务。 |
| 连接码错误 | 复制服务窗口连接码，不要填写 API key。 |
| 模型无权限、密钥错误或余额不足 | 检查服务商账号和配置，修正后重启服务。 |
| AI 无法可靠判断 | 缺少知识或视频上下文，需人工处理，不代表接口故障。 |
| 读取失败或未知反馈 | 暂停并人工核对；提交后的题目不要反复刷新重试。 |
| 浏览器阻止播放 | 手动播放，再点“开始”。 |

## 开发与验证

服务运行只使用 Node.js 内置模块。测试使用 jsdom，锁文件为 pnpm 9 格式：

```sh
pnpm install --frozen-lockfile
pnpm test
```

也可使用 `npm install` 后 `npm test`，但 npm 不会读取 pnpm 锁文件。自动测试通过模拟页面、模拟 AI 和本机回环 HTTP 运行，不调用真实 API、不访问课程账号、不提交课程答案。详情见 [验证结果](验证结果.md)。GitHub Actions 会在推送及拉取请求时运行测试。

适配其他课程或平台需要分别检查页面、控件、提交和反馈逻辑，不应只改网址匹配规则。提交问题时提供脱敏的错误提示和最小复现，不要上传题库、连接码、账号信息或密钥。
